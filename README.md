# Craftistry website

Static website for Craftistry, a 3D printing studio for custom lifestyle and gifting products. Pages: Home, Services, Occasions, Gallery and Contact/Quote.

Plain HTML, CSS and JS with no build step. Open `index.html`, or run `python3 -m http.server 8000` and visit http://localhost:8000.

See `CLAUDE.md` for structure, conventions and brand guidelines.
